# PlayMint

A lightweight, all-ages web game built for phones. No account, backend, API, or app install required.

## MVP
- Random challenges
- Would-you-rather prompts
- Party wheel prompts
- Story starters
- One-tap copy/share
- PWA-ready

## Monetization path
The core game stays free. Paid digital packs can be sold as themed collections: birthday, classroom, family night, road trip, sleepover, date night, team icebreakers, and creator-made packs.

A future pack builder can let creators write 20 prompts, add a title/cover, export a printable PDF, and attach a checkout link. This keeps the first version cheap to operate: static hosting plus payment-provider transaction fees only when a sale occurs.

## Next build
1. Pack builder with localStorage.
2. Export/print-friendly pack pages.
3. Creator checkout-link field.
4. Shareable pack URLs.
5. Optional premium prompt packs.

## Run
Open `index.html` in a browser. The app is intentionally dependency-free.
